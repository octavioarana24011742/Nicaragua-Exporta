 Descripción del proyecto

El proyecto Nicaragua Exporta tiene como propósito organizar, analizar y presentar información relacionada con operaciones comerciales de NicaExport Trading mediante el uso de herramientas digitales.

La información fue procesada en Microsoft Excel utilizando una base de datos de operaciones, fórmulas, funciones, filtros, ordenamiento, tablas dinámicas e indicadores que permiten interpretar el comportamiento de las exportaciones y apoyar la toma de decisiones.

 Contenido del repositorio

 Excel
Contiene el archivo de análisis de comercio internacional con:
- Base de datos de operaciones.
- Fórmulas y funciones.
- Filtros y ordenamiento.
- Cálculo de Valor FOB, costos y utilidad.
- Análisis de rentabilidad.
- Clasificación de operaciones.
- Tablas dinámicas.
- Resumen ejecutivo.

PowerPoint
Contiene la presentación de **8 diapositivas** elaborada con los principales resultados obtenidos durante las primeras tres semanas del proyecto.

Evidencias
Contiene capturas y documentos que demuestran el desarrollo de las actividades, la aplicación de herramientas en Excel y el trabajo colaborativo realizado en GitHub.
